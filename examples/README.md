# Examples

Each directory holds one `.firgit`, named as it would be in a real repo.

- [`basic/`](basic/.firgit) — a typical project: a legacy directory, a
  rename, fake fixtures, a few path patterns.
- [`timed/`](timed/.firgit) — a repo mid-migration, where several things
  are true for a few weeks and then never again. This is the one with
  the dates.
- [`private/`](private/.firgit) — a private repo. Just the owner and the
  agents in here. Mostly notes. Some of them catty.
